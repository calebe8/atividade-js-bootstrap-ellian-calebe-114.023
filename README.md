# Atividade JavaScript e Bootstrap

## Tema do Projeto
Painel de Revisão Web baseado na Aula 5 para revisar HTML, CSS e Bootstrap.

## Componentes Bootstrap Utilizados
* Navbar
* Header (Hero)
* Carousel (Carrossel de imagens)
* Cards e Badges
* Alert (Alerta)
* Buttons (Botões)
* Grid (container, row, col-12, col-md-4)

## Conceitos JavaScript

### Diferença entre let, const e var
* **const:** Valor fixo que não muda.
* **let:** Valor que pode ser alterado depois.
* **var:** Modo antigo que não se usa mais por causar bugs no código.

### Tipos de Dados
* String (texto)
* Number (número)
* Boolean (true/false)
* Null (vazio)

### Condição if/else
O código checa a variável de boletos. Se tiver 4 ou mais pagos, exibe uma mensagem positiva no console. Se tiver menos, avisa para pagar.
